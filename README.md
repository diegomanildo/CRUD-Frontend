# CRUD Web App

This repository contains a sample web application designed to demonstrate the basic functionality of a CRUD (Create, Read, Update, Delete). The goal is to help other developers understand the fundamental concepts and implementation of CRUD operations in a web application, focusing on the frontend.

## Features

- **Create**: Allows users to add new items to a list.
- **Read**: Displays all stored items in a table or list.
- **Update**: Enables editing the data of an existing item.
- **Delete**: Allows deleting items from the list.

## Technologies Used

- **HTML**: Structure of the content.
- **CSS**: Styling the interface.
- **JavaScript**: Application logic and DOM manipulation.

## How It Works

1. **Create**:
   - Fill out the form to add a new item.
   - Click the "Add" button to save it to the list.

2. **Read**:
   - Created items appear in a visible table or list.

3. **Update**:
   - Click the "Edit" button next to an item.
   - Modify the data in the form and save the changes.

4. **Delete**:
   - Click the "Delete" button next to an item to remove it from the list.
